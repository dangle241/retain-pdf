# rendering/workflow

## Responsibilities

Render pipeline orchestration layer. Organizes render tasks, selects render mode, prepares context, dispatches modules.

## Public entry point

- `executor.py`
- `direct_overlay.py`
- `modes.py`
- `context.py`

## What not to do

- No implementation needed. redaction Algorithm.
- No implementation. Typst Source template details.
- Do not implement bbox font adaptation algorithm.
