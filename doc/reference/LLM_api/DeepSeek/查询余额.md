# DeepSeek Query balance

DeepSeek Official balance query interface for checking current API Does the account have any remaining callable balance?RetainPDF if implementing in the frontend or backend DeepSeek Key Detection: use this interface for additional validation. `402 Insufficient Balance` This type of problem.

## Interface

```http
GET https://api.deepseek.com/user/balance
Authorization: Bearer <DEEPSEEK_API_KEY>
Accept: application/json
```

Note: This endpoint does not include `/v1`Chat API default. `base_url` 是 `https://api.deepseek.com/v1`, but the balance endpoint should call `https://api.deepseek.com/user/balance`do not concatenate as `https://api.deepseek.com/v1/user/balance`。

## curl example

```bash
curl -L -X GET "https://api.deepseek.com/user/balance" \
  -H "Accept: application/json" \
  -H "Authorization: Bearer ${DEEPSEEK_API_KEY}"
```

## Success response

```json
{
  "is_available": true,
  "balance_infos": [
    {
      "currency": "CNY",
      "total_balance": "110.00",
      "granted_balance": "10.00",
      "topped_up_balance": "100.00"
    }
  ]
}
```

Field description:

| Field | Type | Description |
| --- | --- | --- |
| is_available | boolean | Does the current account have available balance for API calls? |
| `balance_infos` | `object[]` | Balances by Currency |
| balance_infos[].currency | string | Currency, possibly CNY or USD |
| `balance_infos[].total_balance` | `string` | Total available balance, including bonus and deposit balance. |
| `balance_infos[].granted_balance` | `string` | Unexpired Bonus Balance |
| `balance_infos[].topped_up_balance` | `string` | Recharge Balance |
