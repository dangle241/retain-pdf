# Base contract

This covers only the most basic reading.

## Response wrapper

All business interfaces are unified as:

```json
{
  "code": 0,
  "message": "ok",
  "data": {}
}
```

Read order:

1. First check whether HTTP is 2xx
2. Then check code
3. If code === 0, then read data

Don't read top‑level items, stage, or failure.

## List API

List page main interface.

- `GET /api/v1/jobs`
- `GET /api/v1/ocr/jobs`

Common fields:

- `job_id`
- `display_name`
- `workflow`
- `status`
- `stage`
- `created_at`
- `updated_at`
- `detail_url`
- `invocation`

Recommend treating it solely as a recent task entry; do not embed detail page logic in the list.

## Provider validation

MinerU Token Validation:

- `POST /api/v1/providers/mineru/validate-token`

Purpose:

- Submit OCR token early to validate whether it is available
- Detect expiry, invalidity, or network issues early.

Recommended status to return:

- `valid`
- `unauthorized`
- `expired`
- `network_error`
- `provider_error`

## Basic reading

- Task Status View `status`
- Current Stage View `stage`
- Can I click the button to view? `actions`
- Can it be downloaded and viewed? `artifacts` / `artifacts-manifest`
- See whether the task is truly completed. `status === succeeded`
