# Render parameters

Rendering parameters are in the create task request's render object.

## Common fields

```json
{
  "render": {
    "render_mode": "auto",
    "compile_workers": 0,
    "typst_font_family": "Source Han Serif SC",
    "pdf_compress_dpi": 0,
    "translated_pdf_name": "book-translated.pdf",
    "body_font_size_factor": 0.95,
    "body_leading_factor": 1.08,
    "font_unify_mode": "role_min",
    "source_cleanup_strategy": "pikepdf_text_strip"
  }
}
```

Field description:

- `render_mode`: Rendering Mode.
- `compile_workers`: Typst Compilation concurrency,`0` Default policy.
- `typst_font_family`: Typst Use fonts.
- pdf_compress_dpi: PDF image compression DPI; 0 means no extra compression.
- translated_pdf_name: output PDF file name.
- body_font_size_factor: global font size multiplier for body text.
- `body_leading_factor`: Global body line height multiplier.
- font_unify_mode: common font consistency strategy, role_min or off.
- `source_cleanup_strategy`: Source text processing strategy.

See full specification `backend/rust_api/RENDER_OPTIONS_CONTRACT.md`。
