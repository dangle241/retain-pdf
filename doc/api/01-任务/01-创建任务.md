# Create task

## Endpoint

```http
POST /api/v1/jobs
```

Create a book, translate, or render task.

## workflow

- `book`: OCR -> Normalize -> Translate -> Render。
- `translate`: OCR -> Normalize -> Translatedo not render PDF。
- `render`: Reuse existing artifacts; only re-render.

OCR-only tasks use a separate endpoint; see OCR-only tasks.

## JSON Request Example

```json
{
  "workflow": "book",
  "source": {
    "upload_id": "upload-xxx"
  },
  "ocr": {
    "provider": "paddle",
    "paddle_token": "secret",
    "options": {
      "paddle_model": "PaddleOCR-VL-1.6"
    }
  },
  "translation": {
    "api_key": "secret",
    "base_url": "https://api.deepseek.com/v1",
    "model": "deepseek-v4-flash",
    "workers": 100,
    "batch_size": 1
  },
  "render": {
    "render_mode": "auto",
    "source_cleanup_strategy": "pikepdf_text_strip"
  }
}
```

## Key fields

- `source.upload_id`: Returned by the upload API.
- source.source_url: remote PDF URL, depends on whether the provider supports URL.
- `ocr.provider`: `mineru`、`paddle`、`local` Or configuration type command provider。
- `ocr.options`: provider-specific Parameters: prioritize non-secret config.
- `translation`: Translation model, concurrency, terminology table, and context configuration.
- `render`: Rendering parameters.

## Response

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "job_id": "20260616120000-abcdef",
    "status": "queued"
  }
}
```

Frontend gets. `job_id` Then start polling:

- `GET /api/v1/jobs/{job_id}`
- `GET /api/v1/jobs/{job_id}/events`
