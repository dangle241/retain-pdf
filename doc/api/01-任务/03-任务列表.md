# Task list

## Endpoint

```http
GET /api/v1/jobs
```

Displays recent tasks, library entry, and task card list.

## Query params

The filtering and pagination capabilities supported by the current implementation are based on the API response. The frontend should avoid relying on local cache as the final state.

## Response focus

List items should contain:

- `job_id`
- `status`
- `display_stage`
- `stage`
- `substage`
- `lane`
- `progress`
- `display_name`
- `page_count`
- `source_file_name`
- `cover_url`
- `thumbnail_url`
- `output_pdf_ready`
- `markdown_ready`
- `bundle_ready`

## Frontend rules

- List cards use list API snapshot; no immediate per-item fetch. job detail。
- Image Usage `cover_url` / `thumbnail_url`When empty, frontend uses placeholder image.
- Do not scan local filesystem or concatenate. job Contents.
