# Download overview

## Artifact API

```http
GET /api/v1/jobs/{job_id}/artifacts
GET /api/v1/jobs/{job_id}/artifacts-manifest
GET /api/v1/jobs/{job_id}/artifacts/{artifact_key}
```

Prefer frontend to use artifact manifest exposed keys and URLs; do not directly concatenate file paths.

## PDF

```http
GET /api/v1/jobs/{job_id}/pdf
GET /api/v1/jobs/{job_id}/pdf/side-by-side
```

- `/pdf`: translated PDF。
- `/pdf/side-by-side`: Side-by-side synthesis of source and translation PDF。

## Images and preview

```http
GET /api/v1/jobs/{job_id}/cover
GET /api/v1/jobs/{job_id}/thumbnail
GET /api/v1/jobs/{job_id}/preview/pages/{page}
```

## Markdown

```http
GET /api/v1/jobs/{job_id}/markdown
GET /api/v1/jobs/{job_id}/markdown?raw=true
GET /api/v1/jobs/{job_id}/markdown/document
GET /api/v1/jobs/{job_id}/markdown/images/{path}
```

- `/markdown`: Default: include images. URL Document view or download response.
- `?raw=true`: return original Markdown File stream.
- /markdown/document: returns JSON structure, suitable for frontend display and AI Q&A.
- `/markdown/images/{path}`: Get Markdown Refer to image.

## Bundle

```http
GET /api/v1/jobs/{job_id}/download
```

Used for downloading task-related artifact packages.
