# Context, terminology, and memory patterns

These three fields control prompt Injection scope: do not disable final quality fallback.

## context_mode

Available values:

- `needed`: Default. Only provide context for incomplete fragments, continuation paragraphs, captions, and other items that require context item Inject context.
- `all`: Revert to heavier full-neighbor context behavior.
- `off`: No context provided.

## glossary_mode

Optional values:

- matched: default. Only inject terms matched to current item or batch.
- `all`: Inject the entire glossary.
- `off`: No inject glossary.

## memory_mode

Optional values:

- matched: default. Only inject document memory hits for current item or batch.
- `broad`: Inject a broader document-level summary.
- off: disable memory injection.

## Quality Fallback

These options only affect prompt budget. Items with should_translate=true must not result in empty translations. Empty translations, severe English remnants, and placeholder errors must still enter the fix pipeline.
