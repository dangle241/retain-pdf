# Translate events

Translation events via unification. job events Expose:

```http
GET /api/v1/jobs/{job_id}/events
```

## Common substage

- `translation_prepare`
- `domain_inference`
- `page_policies`
- `continuation_review`
- `translation_batches`
- `garbled_repair`
- `translation_review`

## Event examples

```json
{
  "seq": 120,
  "display_stage": "translation",
  "stage": "translating",
  "substage": "translation_batches",
  "lane": "main",
  "event_type": "progress",
  "progress": {
    "unit": "batch",
    "current": 789,
    "total": 5216,
    "percent": 15.1
  },
"stage_detail": "Translating batch 789 / 5216"
}
```

## Frontend rules

- Translation progress reads display_stage=translation and lane=main.
- progress.unit may be batch, page, item, or step; show by return value.
- `stage_detail` Human-readable text only.
- Background rendering warm-up event will be `display_stage=render`、`lane=background`, do not override the main translation status.
