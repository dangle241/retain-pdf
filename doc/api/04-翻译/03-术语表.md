# Glossary

Glossary accessible via resources. ID References may also be passed inline with the task request.

## Task field

```json
{
  "translation": {
    "glossary_id": "glossary-xxx",
    "glossary_name": "chemistry",
    "glossary_entries": [
      {
        "source": "bond",
"target": "bond",
        "note": ""
      }
    ]
  }
}
```

## Glossary API

```http
POST /api/v1/glossaries/parse-csv
POST /api/v1/glossaries/import
GET /api/v1/glossaries
POST /api/v1/glossaries
GET /api/v1/glossaries/{glossary_id}
PUT /api/v1/glossaries/{glossary_id}
DELETE /api/v1/glossaries/{glossary_id}
GET /api/v1/glossaries/{glossary_id}/export.csv
```

## Frontend rules

- Glossary resource management `/glossaries`。
- Pass first on task creation. `glossary_id`。
- A few temporary terms may be passed along with the task. `glossary_entries`。
- Term injection strength `translation.glossary_mode` Control.
