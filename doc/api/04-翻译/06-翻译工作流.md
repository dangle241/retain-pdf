# Translation workflow

## book workflow

`workflow=book` Main chain:

```text
OCR child -> normalize -> translate -> render
```

Rust Prepare first. OCR Then start translation phase. After success, continue rendering.

## translate workflow

workflow=translate main chain:

```text
OCR child -> normalize -> translate
```

After translation is completed, the task ends and no final PDF。

## Reuse existing OCR artifact

If request includes `source.artifact_job_id`Backend can reuse existing. OCR artifacts, directly prepare translation input, no need to re- OCR。

## Translation phase input

- `source_json`: normalized `document.v1.json`
- source_pdf: source PDF
- `layout_json`: provider layout/result JSONcan be used for diagnosis or supplementary information.

## Translation phase output

- translation manifest
- page translation payloads
- diagnostics
- debug index
- review artifact

Rendering phase should only consume translation outputs and source PDF, should not read back OCR provider private fields.
