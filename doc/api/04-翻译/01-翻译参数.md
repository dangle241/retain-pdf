# Translate parameters

Translation parameters in create task request. `translation` In the object.

## Common fields

```json
{
  "translation": {
    "api_key": "secret",
    "base_url": "https://api.deepseek.com/v1",
    "model": "deepseek-v4-flash",
    "workers": 100,
    "batch_size": 1,
    "mode": "sci",
    "math_mode": "direct_typst",
    "context_mode": "needed",
    "glossary_mode": "matched",
    "memory_mode": "matched"
  }
}
```

Field description:

- `api_key`: Downstream large model API keyResponse not echoed.
- `base_url`: Downstream model OpenAI-compatible base URL。
- `model`: DeepSeek.
- `workers`: concurrency
- `batch_size`: Translation per request item Number.
- `mode`: Translation mode active. Send source.
- `math_mode`: Formula processing mode: current default `direct_typst`。
- `context_mode`: Context injection strategy.
- `glossary_mode`: Terminology injection strategy.
- `memory_mode`: Translation memory injection strategy.

## Frontend rules

- Basic UI shows only core options: model, concurrency, glossary, etc.
- `context_mode`、`glossary_mode`、`memory_mode` Better as advanced option.
- Do not save api_key to visible logs or events.
